## UI components: shadcn-vue

- Need a component? `cd web/app && pnpm dlx shadcn-vue@2.9.0 add <name>`, then `pnpm format`; it lands in `src/components/ui/<name>/`. Adapt it there and import it from its folder (`import { Button } from '@/components/ui/button'`).
- Components style with the theme's variables (`bg-card`, `text-muted-foreground`), never a colour of their own. `src/index.css` holds two palettes of the same variables, `:root` (light) and `.dark` (dark), swapped as a whole; their colours are `fabric.yaml`'s colour scheme (`frontend.color-scheme`) on slate, so never edit a colour of them by hand. Change the radius in `:root`. `src/theme/contrast.test.ts` fails when a text colour has less than 4.5:1 on its background in either.
- The app follows the system's theme (`prefers-color-scheme`) until the user picks light, dark or system in `ThemeToggle.vue` (`src/theme/`), in the app's navigation. The choice is kept in `localStorage` under `theme`, which `index.html`'s script reads to set `.dark` on `<html>` before the first paint. Style what differs in the dark theme with the `dark:` variant or the palette, never by reading the theme in a component.
{{~ if project["frontend.design-system"] == "tokens" || project["frontend.design-system"] == "web-components" ~}}
- A colour or radius the design system's tokens define (`primary`, `accent`, `border`, `rounded-md`, …) is changed in its token, not in `:root`: the tokens are imported after the theme and win. A colour token has its light value in `web/packages/tokens/src/color.tokens.json` and its dark one in `web/packages/tokens/dark/color.tokens.json`: change both, and `src/theme/contrast.test.ts` checks them as built, over the palettes.
{{~ end ~}}
- The CLI names files in one word (`Dialog.vue`); give each component a name in two with `defineOptions({ name: 'UiDialog' })`, as `Button.vue` does, or lint fails.
- Compose screens from those components; do not install PrimeVue, Vuetify, Quasar, Element Plus, Ant Design Vue, Naive UI or Headless UI (lint refuses them).
