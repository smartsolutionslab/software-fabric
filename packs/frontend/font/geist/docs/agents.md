## Font: Geist

- The app's typeface is Geist, with Geist Mono for monospace text, `fabric.yaml`'s font (`frontend.font`): the npm packages `@fontsource-variable/geist` and `@fontsource-variable/geist-mono`, imported in `src/index.css` and bundled with the app, never from a font host. Never add a `<link>` or an `@import` of Google Fonts or another CDN: `src/theme/font.test.ts` fails on anything `index.html` or `src/index.css` loads from another host.
- The theme's `--font-sans` names Geist and `--font-mono` Geist Mono; text takes them through `font-sans` (the page's default) and `font-mono` (identifiers, codes), never a `font-family` of a component's own.
- To switch to the other font (Inter or Geist), run `fabric change --set frontend.font=<font>` in a clean working tree: it changes the imported package in `src/index.css` and `package.json` and the theme's font names, records the font in `fabric.yaml` and keeps the project's other edits, as a merge left uncommitted for review; then run `pnpm install` so the lockfile names the new package. Never edit the font in `fabric.yaml`, the theme or the imports by hand; `fabric upgrade` keeps the recorded font.
